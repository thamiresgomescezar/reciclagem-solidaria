Política de Privacidade

1. Dados coletados

O sistema Reciclagem Solidária coleta os seguintes dados dos usuários cadastrados:

  • Nome completo;
  • E-mail (utilizado como login);
  • Telefone para contato;
  • Endereço (rua, número, complemento, bairro, cidade, estado, CEP) ou a opção "Sem moradia";
  • Fotos de materiais recicláveis enviadas nas ofertas de coleta.

2. Como os dados são utilizados

Os dados são utilizados exclusivamente para:

  • Autenticação e controle de acesso por perfil (Administrador, Cidadão Consciente, Catador);
  • Comunicação entre os participantes para agendamento de coletas;
  • Geração de relatórios geográficos e de desempenho (dados agregados);
  • Gestão institucional da coleta seletiva na Fatec Franco da Rocha.

3. Compartilhamento

Os dados sensíveis (endereço completo, e-mail) são visíveis apenas ao próprio usuário e aos administradores. O diretório público de catadores expõe apenas nome e telefone. Nenhum dado é vendido ou compartilhado com terceiros fora do contexto acadêmico-institucional.

4. Armazenamento e segurança

As senhas são armazenadas de forma segura pelo Supabase Auth (hash), nunca em texto puro. O acesso aos dados é controlado por políticas de segurança (RLS) no banco de dados.

5. Cookies

O sistema pode utilizar cookies para manter a sessão de navegação, respeitando as configurações do navegador.

6. Contato

Para dúvidas sobre esta política, contate a administração da Fatec Franco da Rocha.
